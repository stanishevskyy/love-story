# 💖 Love Story

A personal romantic website created as a gift for my wife.

The project tells our story through beautiful animations, memorable moments, and interactive sections that celebrate our journey together.

## ✨ Features

- Elegant hero section with smooth animations
- Interactive love story timeline
- Photo gallery with memorable moments
- Days together counter
- "100 Reasons Why I Love You" section
- Animated love letter
- Surprise section with confetti effects
- Background music player
- Fully responsive design
- Smooth scrolling and micro-interactions

## 🛠️ Tech Stack

- HTML5
- JavaScript (Vanilla JS)
- Tailwind CSS 4
- Vite
- Framer-inspired animations using pure CSS and JavaScript

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/love-story.git
cd love-story
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
